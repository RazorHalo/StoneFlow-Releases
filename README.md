# StoneFlow

StoneFlow is a production tracker for stone fabrication shops, built on Moraware JobTracker, by StoneFlow Technologies.

This repository holds the installers and updates. It contains no source code.

## Install

1. Open the newest entry under **Releases**.
2. Download `StoneFlow-stable-Setup.exe` (or `StoneFlow-beta-Setup.exe` if you were asked to test a beta).
3. Run it. Windows will show "Windows protected your PC" because the installer is not signed yet: choose **More info**, then **Run anyway**.
4. StoneFlow opens when the install finishes. Open **Settings** and enter your Moraware login.

StoneFlow installs for the current Windows user and needs no administrator rights.

## Updates

StoneFlow checks this page for a newer version in the background. When one is ready, a **Restart to update** button appears at the bottom of the window. Nothing restarts until you click it.
